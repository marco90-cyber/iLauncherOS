# iLauncherOS

Launcher Android in stile iPhone (ispirato a "Launcher OS Pro"), Kotlin + Jetpack Compose.

**Funzioni (dal video di riferimento)**
- Home con griglia 4×5 / 4×6 / 4×7, dock traslucido, pagine con indicatori, barra Cerca, swipe verso il basso per la ricerca
- Modalità Edit: icone che tremano, badge "−", trascinamento con riordino live, cambio pagina ai bordi, menu Edit (Add Widget, Customize Theme, Edit Wallpaper)
- Widget: Orologio analogico/digitale, Calendario, Meteo (Open-Meteo), Batteria + widget Android di sistema; selettore con ricerca; ridimensionamento
- App Library con categorie e ricerca
- Impostazioni: General, Change App Icon (forma/dimensione), Homescreen Style, Screen Grid, Page Transition, App nascoste, Libreria, Rinomina app, Badge notifiche, Lingua (EN/IT), Appearance (Light/Dark/Auto/System), Meteo
- APK compilato da GitHub Actions (Actions → Build APK → artifact)
